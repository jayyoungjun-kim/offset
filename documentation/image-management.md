# 썸네일 이미지 관리

## 운영 방법
- 어드민 → 프로그램 수정 → 썸네일 이미지: 업로드 또는 기존 이미지 선택 → 변경 사항 저장.
- 썸네일 제거 → 변경 사항 저장 시 리스트·상세가 회색 공란으로 바뀐다. 보관함 원본은 남아 재사용할 수 있다.
- 어드민 → 이미지 관리: 업로드, 크기/용량/사용 프로그램 확인, 미사용 이미지 삭제.
- 실제 운영은 관리자 Google 로그인 후 가능하다. `/admin/preview`에서는 변환·선택·삭제만 체험하며 업로드 이미지는 새로고침하면 사라진다.

## 이미지 처리
- JPG/PNG/WebP, 원본 최대20MiB·40MP. GIF/SVG 등은 지원하지 않는다.
- 브라우저에서 긴 변 최대1600px로 줄이고 WebP 품질·해상도를 단계적으로 낮춰 최대500KiB로 변환한다. EXIF 등 원본 메타데이터는 전달하지 않는다.
- 4:3 프레임 안에 이미지 전체를 표시한다. 다른 비율은 잘라내지 않고 공란 여백을 둔다.
- 변환된 이미지만 서버에 전송·보관한다. 변환 오류나 저장 오류 시 기존 썸네일 선택을 유지한다.

## 저장과 권한
- `.openai/hosting.json`의 MEDIA R2 바인딩 사용. `thumbnails/{uuid}.webp`로 저장하며 이름·치수는 객체 메타데이터로 관리한다.
- `/api/admin/media` GET/POST/DELETE: 관리자 권한 필수. 쓰기 요청은 동일 출처 확인, 업로드는 스트림 용량 상한·WebP 헤더·정적 이미지 여부·치수 검증.
- `/media/{id}`: 공개 썸네일 응답. 이미지 MIME 고정, nosniff, 캐시1시간.
- 프로그램 저장 시 선택 이미지의 존재 확인. 사용 중 이미지 삭제는409로 거절한다. 보관함은100개 단위로 더 보기 지원.
- 기존 장식 이미지 경로는 프로그램 조회 시 공란으로 취급한다. 신규/샘플 프로그램 기본값도 공란이다.

## 검증
- 서버 테스트: 관리자 권한, CSRF, R2 업로드·조회, 프로그램 연결·해제, 사용 중 삭제 방지, 삭제 후404, 잘못된 형식·용량 초과 거절.
- 브라우저: 데스크탑/모바일 공란4:3, 원본2400×1800 노이즈 PNG → WebP1200×900/476092바이트, 선택·제거·보관함 삭제.
