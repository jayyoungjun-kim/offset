# 회원과 신청 관리

## 실제 회원 흐름
Google 로그인 → 프로그램 신청 → 신청 접수 → 마이페이지에서 상태 확인 → 운영자 검토 → 참가 가능/불가 안내.

회원은 자신의 이름·이메일, 신청 일시, 신청 상태, 신청 번호, 지원 동기, 포트폴리오 링크를 확인한다. 운영자는 동일 신청 레코드의 상태를 변경한다. 참가 가능은 결제나 수강 완료를 뜻하지 않으며, 결제·그룹 일정은 별도로 안내한다. 신청 수정·취소가 필요하면 신청 번호가 포함된 이메일 문의를 이용한다.

## 화면
- /account: 로그인한 회원 본인의 신청만 표시. 요약, 상태 필터, 신청서 펼치기, 회원 정보, 로그아웃.
- /admin: 관리자 권한으로 신청자 이름·이메일·신청 시각·프로그램·회원/신청 ID·동기·포트폴리오 확인 및 상태 변경.
- /admin/preview: 샘플5명 표시. 가상 이름과 example.com 주소 사용. 신청 상태는 이 브라우저의 샘플 저장소에서만 변경.
- /account/preview: 어드민 샘플과 연결된 회원 선택. 같은 브라우저의 상태 변경을 반영.

## 현재 제약
Google OAuth 및 관리자 이메일 서버 설정은 아직 필요하다. 미리보기는 인증 우회가 아니며 실제 회원이나 실제 신청을 생성하지 않는다. 영구 회원 데이터는 기존 D1의 본인/관리자 권한 검사를 통해서만 접근한다.
