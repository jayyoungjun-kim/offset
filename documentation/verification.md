# 검증 기록 · 2026-09-07

환경: Node 24.19.0, 고정된 기존 의존성, Vinext 0.0.50, Wrangler 4.92.0, 로컬 D1.

## 자동 검증

- TypeScript 타입 검사.
- 신규 플랫폼 코드 ESLint 오류 검사.
- 운영 Worker 프로덕션 빌드.
- Worker 런타임에서 14개 통합 테스트.
  - 공개 목록 및 모집 마감 초기 데이터.
  - 미인증·일반 회원·위조 세션의 관리자 접근 차단.
  - 교차 출처 요청과 익명 신청 차단.
  - 초안 저장, 공개 목록 제외, 직접 URL 404.
  - 중복 주소·잘못된 가격·이미지 경로 입력 차단.
  - 프로그램 수정의 목록 및 상세 반영.
  - 동의 및 포트폴리오 URL 검증, 정상 신청, 중복 신청 차단.
  - 마감 직전 상태를 가지고 있던 클라이언트의 신규 접수 차단.
  - 회원별 신청 내역 격리, 운영자 변경 상태 반영.
  - 확장용 콘텐츠 원고 저장.
  - Google 설정 누락 및 잘못된 callback의 로그인 실패 처리.
  - 로그아웃 이후 서버 세션 폐기.
  - 기존 홈 HTML 및 메타데이터.
  - 기존 공개 페이지와 신규 플랫폼 페이지의 서버 렌더.

기존 Node 직접 import 테스트는 cloudflare:workers 바인딩을 지원하지 않아 Worker 런타임 기반 테스트로 이관했다. 기존 검증 내용을 삭제하거나 통과 조건을 완화하지 않았다.

## 문서 검증

9쪽 PDF를 PNG로 렌더링하고 전체 페이지 배치 및 한글 본문을 확인했다. 처음 생성한 문서의 제목 파싱 문제를 수정하고 최종 PDF를 다시 렌더링했다. 최종 PDF의 텍스트와 페이지 수를 재확인했다.

## 아직 검증하지 않은 범위

실제 Google 자격 정보가 제공되지 않아 실제 계정으로 로그인하는 왕복 과정은 확인하지 않았다. 운영 배포·공개 도메인 전환·원격 데이터베이스 작업은 수행하지 않았다. 브라우저 기반 모바일/데스크탑 상호작용·시각 QA는 아직 수행하지 않았다. 참고 사이트는 실제 브라우저에서 읽었고 개발 화면은 로컬 미리보기로 제공했다.
